# 一词多义 · 斩词达人

初中文言实词「一词多义」练习小游戏 —— 单文件网页，双击即玩，也可直接托管。

**玩法**：屏幕给出一句文言文，句中加粗高亮的字就是要考的实词，从四个义项中选出**该句中的意思**。

- 四种模式：快问快答 20 题 / 限时挑战 3 分钟 / 闯关 3 条命 / 全部题目摸底
- 速览词卡（`←` `→` 翻卡，`空格` 遮/显释义）
- 排行榜按得分+正确率+用时排序，四种模式分开统计
- 名单支持点选、手输、按行批量导入整班
- 名单存在本机浏览器（localStorage）
- 排行榜：接入线上存储时为**全班共享榜**（所有设备看到同一份成绩）；
  未接入、或服务暂时不可达时自动改用本机记录，页面会写明当前是哪种模式

**题库**：《中考精编·讲义册（古诗文）》第三章「文言文阅读 ·【三】初中文言文一词多义汇编」，
收录该表所引全部篇目（含九年级下册与课外篇目），共 114 字 / 327 题。

本目录只有打包好的 `index.html`（约 96 KB；除线上排行榜外不发起外部请求）。
源文件、OCR 工具链与验收脚本在开发仓库里，不在此发布仓库中。
